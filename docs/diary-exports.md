# 日記の書き出しと日付の扱い

現行の `index.html` の4形式の書き出し仕様。保存済みの記録は変更しない。

- HTML・CSV・テキストは日付を日本時間で表示。画面・期間検索・年月統計も日本時間。
- JSONは日付をISO 8601（UTC）で出力する。
- ISO文字列、Date、Firebase Timestamp、シリアライズ済みTimestamp、Unixミリ秒を読み取る。タイムゾーンのないISO日時は日本時間として扱う。
- 不正・欠落した日付は「日付不明」、JSONでは `null`。不明日付は期間検索・年月統計から除外するが、総件数からは除外しない。
- ログイン中の本人の読み込み済み記録をすべて書き出す。検索フィルターは書き出し対象を制限しない。
- HTMLでは本文などを文字としてエスケープする。CSVはUTF-8 BOM付きで改行・引用符を保持し、数式に見えるセルの先頭にアポストロフィを付ける。
- ブラウザーの保存完了は判定できないため、画面の通知はファイル準備完了を意味する。保存先・ダウンロードの完了はブラウザーで確認する。
- 写真を取得・公開する処理は行わない。JSONの既存 `imageUrl` 情報は残すが、これらの形式は写真を含む完全なバックアップ・復元機能ではない。

## 検証

```sh
TZ=UTC node --test tests/memory-export.test.cjs
TZ=America/Los_Angeles node --test tests/memory-export.test.cjs
npm test
npm run build
```

単体テストは架空の記録を使い、本番の記録を作成・編集・削除しない。ブラウザーでの検証でも実際の記録の変更は不要。
